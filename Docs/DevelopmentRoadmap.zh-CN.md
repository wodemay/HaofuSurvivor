# 开发路线图

本文只记录尚未实现或需要扩展的工作，不重复当前模块细节。

## 近期

- 补充存档版本、校验、损坏恢复、备份和继续游戏摘要。
- 补充 Unity Test Framework 的 System、Command、Query 测试，以及主场景 Play Mode 回归。
- 为地图 NavMesh、区块流式加载、对象池跨场景恢复和动态 Tick 注册增加自动化验证。

## 战斗与成长

- 远程、范围、激光、召唤和 Boss Attack 的完整配置与表现。
- 更完整的 Weapon、Skill、Dodge 候选权重、稀有度和局内成长内容。
- 完整掉落表、金币、宝箱和更多奖励来源。

## 局外与世界内容

- Profile 永久存档、金币、局外经验和永久升级。
- 角色、武器、地图、成就和图鉴解锁。
- 设置页、音频、本地化和输入设备适配。
- 更多敌人阶段、精英、Boss、地图事件、物品指示箭头、地图边界和胜利条件。

## 性能与工具

- 对象池容量监控、NavMesh/区块加载性能采样和存档写入指标。
- 依据采样结果评估实体批处理与 `.asmdef` 编译隔离。

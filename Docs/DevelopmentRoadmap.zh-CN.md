# 开发路线图

本文只记录尚未实现或需要扩展的工作，不重复当前模块细节。

## 近期

- 补充存档版本、校验、损坏恢复和继续游戏摘要。
- 补充 Unity Test Framework 的 System、Command、Query 测试，以及主场景 Play Mode 回归。
- 为统一 Tick 增加暂停、注册/注销和对象池复用的自动化验证。

## 战斗与成长

- 远程敌人攻击的完整配置与表现。
- 范围、激光、召唤和 Boss 多 Attack 组合。
- 新 Weapon、Skill、闪避升级候选、权重、刷新、跳过、稀有度。
- 完整掉落表、金币和宝箱。

## 局外与内容

- Profile 永久存档、金币、局外经验和永久升级。
- 角色、武器、地图、成就和图鉴解锁。
- 设置页、音频、本地化和输入设备适配。
- 更多敌人阶段、精英、Boss、地图边界、胜利条件与关卡事件。

## 性能

- 对象池容量监控、性能采样和存档写入指标。
- 依据采样结果评估进一步的实体批处理与 `.asmdef` 编译隔离。
